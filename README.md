# 📈 K-TradingAgents — 한국 주식 멀티 에이전트 분석

GitHub의 [TradingAgents](https://github.com/TauricResearch/TradingAgents) 멀티 에이전트 개념을 참고해 만든
한국 주식 분석 프로그램입니다. 3개의 에이전트가 파이프라인으로 협업하며,
모든 판단은 **Signal(증거 객체)** 로 저장되어 근거 텍스트까지 추적됩니다.

| 에이전트 | 역할 |
|---|---|
| 🗞️ **Agent 1** (`agents/news_agent.py`) | 네이버 증권 뉴스·공시 수집 → 가중 키워드 사전 + 공시 유형별 이벤트 규칙(유상증자/자사주/감자 등) + 유사 기사 클러스터링(Jaccard) + 시간 감쇠(반감기 3일) 감성 점수. 강한 악재는 **베토** 플래그 |
| 📊 **Agent 2** (`agents/technical_agent.py`) | 일별 시세 약 250거래일 → MA5/20/60, RSI(문맥형), MACD, 볼린저밴드 %B, ATR, 상대거래량, OBV(다이버전스 포함), MA20 기울기. **추세 35% / 모멘텀 25% / 거래량 25% / 위치·변동성 15%** 4축 점수 + 합의(confluence) 배수. KOSPI 60일선 기반 시장 레짐 판정, 이상치(액면분할 의심) 방어, 간이 백테스트 포함 |
| 🧠 **Agent 3** (`agents/strategy_agent.py`) | 종합 = 기술 65% + 뉴스 35% (재료-차트 일치 ×1.1 / 상충 ×0.8). 스윙 로우/하이 + ATR로 매수·손절·목표가 산출, 손익비 1.5R 미달 시 진입 보류. 판단 근거를 **결론 → 주도 근거(기여도%) → 상충 신호 → 무효화 조건 → 뉴스 인용** 5단 구조로 생성 |

## 🏆 오늘의 후보 종목 (스크리너)

사이드바에서 모드를 전환하면 전 시장 2단계 스크리닝을 실행할 수 있습니다 (`agents/screener.py`):

1. **1단계 (싼 필터)**: 네이버 시가총액 상위 목록에서 거래대금 상위 N종목(우선주/스팩/ETF 제외)을 뽑고,
   차트 JSON API(종목당 요청 1번)로 일봉을 받아 근사 기술 점수를 계산
2. **2단계 (풀 분석)**: 상위 K종목만 뉴스 수집 포함 3-에이전트 파이프라인 실행 → 종합 점수 랭킹
3. 랭킹의 **상세 →** 버튼을 누르면 캐시된 풀 분석 결과가 종목 분석 화면에 표시됩니다

LLM을 호출하지 않는 규칙 기반이라 토큰 비용은 0이며, 비용은 HTTP 요청 수(약 N+30회)뿐입니다.

## 투자 매력 점수 (0~100)

매수/관망/매도 3분법 대신 **100점 만점 점수**가 1차 판단 지표입니다 (`agents/scoring.py`):

- **점수 = 과거 분포의 백분위**: 원점수(기술 4축 가중 합)를 임의 환산하지 않고, 풀드 백테스트
  표본 4만 종목-일 분포에서 "상위 몇 %인지"로 변환 → 83점 = 과거 상위 17% 신호
- **점수 산출 정보 패널**: 원점수 → 백분위 매핑 근거, 해당 점수 구간의 과거 10일 승률·평균 수익률,
  전체 기준선까지 화면에 표시 — 점수가 어디서 왔는지 항상 검증 가능 (LLM 미사용, 수식 기반)
- 보정 테이블(`agents/calibration.json`)은 `python calibrate.py`로 재생성
- 기존 의견(매수 고려/관망/비중 축소)은 참고 라벨로 유지

## 커뮤니티 관심 (참고 지표)

레딧 인기주처럼 "시장이 지금 무엇을 보고 있나"를 수치화하되, 점수에는 반영하지 않습니다 (`agents/community.py`):

- **네이버 금융 검색상위 30**: 순위·검색비율 (후보 탭에 전체 목록, 상세/랭킹에 해당 종목 표시)
- **종목토론실 활성도**: 오늘 게시글 수가 평소 하루 평균 대비 몇 배인지
- 관심 급증은 급등·급락 양쪽에서 발생하는 방향 없는 지표라서 참고용으로만 표시

## 판단 로직 요약

- **뉴스는 확인용**: 감성 점수는 화면 표시만 하고 종합 점수에 반영하지 않는다
  (과거 뉴스 데이터가 없어 백테스트 검증이 불가능하기 때문). 종합 점수 = 기술 점수 100%
- **의견**: 종합 ≥ 매수 임계 그리고 상방 축 ≥ 1개·하방 축 0개 → "매수 고려" /
  ≤ -0.25 → "비중 축소 고려" / 그 외 관망(사유 코드 부여)
- **매수 임계 +0.30 (백테스트 보정)**: 유동성 상위 150종목 × 250거래일 풀드 백테스트(표본 4만 종목-일,
  `calibrate.py`) 결과 — 점수 ≥ 0.30 신호의 10일 평균 +4.3%/승률 54% (기준선 +3.0%/53%), 점수 p99는 +0.38
- **임계 보수화**: 고변동 종목(ATR ≥ 5%) 또는 시장 역풍(KOSPI < 60일선) 시 +0.10
  — 둘이 겹쳐도 합산 +0.10로 캡 (약세장에서 같은 원인을 이중 벌점하지 않기 위해).
  약세 레짐은 백테스트에서 기준선 -1.9%/승률 46%로 확인되어 가산이 정당화됨
- **베토**: 최근 5일 내 강한 악재 공시(점수 ≤ -0.7) 발생 시 기술 신호와 무관하게 매수 보류 (뉴스의 유일한 점수 개입)
- **손절가**: 스윙로우 − 0.5ATR (구조적), 지지선이 멀면(> 2.5ATR) 2ATR 변동성 손절
- **목표가**: 1차 = min(저항선, 2R), 2차 = 3R — 저항까지 1.5R 미만이면 "손익비 부족"으로 관망
- **백테스트**: 근사 점수 시계열로 같은 종목 과거 구간의 "신호 발생 → 10일 후" 승률/평균 수익률 표시

## 주의

- 네이버 증권 페이지 구조가 바뀌면 크롤링이 실패할 수 있습니다.
- 점수 가중치·임계값은 검증되지 않은 설정값이며 백테스트는 근사 통계입니다.
- 본 프로그램은 교육·연구 목적의 규칙 기반 도구이며 **투자 권유가 아닙니다**.
  투자의 최종 판단과 책임은 투자자 본인에게 있습니다.
